# FRIEND FIGHTERS — 친구 대전 격투 🥊

철권 스타일의 2D 픽셀아트 격투 게임. HTML5 Canvas + 순수 JavaScript.
브라우저에서 바로 실행되며 빌드 과정도, 외부 라이브러리도 없습니다.

**플레이: https://kjmedia24-cyber.github.io/friend-fighters/**

### 커맨드 (철권식)

- **→→** 앞스텝 (스텝 중 공격 = 치고 들어가기) / **←←** 백대시
- **→ + 손/발**: 오버핸드 좌/우 (중단) · 앞차기 (중단 푸시킥)
- **← + 손/발**: 백스핀 훅 · 어퍼컷 (미니 띄우기) · 뒤돌려차기 (한 방 하이킥)
- **↓→ + 펀치** 필살기 (캐릭터별)
- **↓→ + 킥** 띄우기 → **공중 콤보** (3~10히트)
- **↓ + 왼발** 짠발(하단) / **↓ + 오른발** 스윕(하단·다운)
- **왼손+오른손 동시** 잡기 — 잡힌 직후 펀치를 누르면 풀기
- `M` 음소거 / `Esc` 뒤로

### 가드 시스템

- **가드 버튼**을 누르고 있으면 가드 (앉은 채 누르면 하단 가드)
- 가드는 **게이지를 소모** — 게이지가 바닥나면 **가드 브레이크 → 그로기** (암전 + 무방비)
- 맞기 **직전(7프레임 이내)에 가드** = **퍼펙트 가드!** 상대는 2초간 공격·가드 **봉인** (이동만 가능)
- 게이지는 가드를 풀면 서서히 회복

### 상단 / 중단 / 하단 (철권의 핵심)

- **상단**: 앉으면 통째로 빗나감. 서서 가드 가능
- **중단**: 앉아 가드를 뚫음. 서서 가드만 가능
- **하단**: 서서 가드 불가. **앉아(↓+뒤) 가드만** 가능
- 캐릭터별 **스트링(연속기)**의 마지막 타가 상단/하단으로 갈려서 가드 심리전 발생
- **카운터 히트**: 상대 공격 시동 중에 맞히면 1.4배 + 길게 휘청

## 캐릭터

| | 림준 | 리동이 | 림준범 |
|---|---|---|---|
| 타입 | 밸런스 콤보형 | 리치 트릭스터 | 파워 그래플러 |
| 특징 | 공중콤보 최강, 체력 30%↓ 각성 "긍정의 왕" | 팔다리 김, 장풍+가드 반격 | 느리지만 한 방 최강, 잡기 특화 |
| ↓→+펀치 | 빡오더 (콤보 시동 버프) | 제미나이 소환 (드론 장풍) | 주차비 정산 (커맨드 잡기, 가드 불가) |
| ↓←+펀치 | — (각성: 긍정의 왕) | 쿠킹호일 실드 (받아치기) | 다이렉트 시술 (카운터 한 방) |

캐릭터 수정/추가는 **`js/data.js` 한 파일만** 고치면 됩니다 (이름·외형·체격·대사·스트링·필살기 전부).

## 시스템

- 2인 로컬 대전 + AI 대전 (쉬움/보통/어려움) + **연습 모드** (무한 체력, 커맨드 리스트 표시)
- 스테이지별 칩튠 **BGM** + WebAudio 효과음, 모바일 **터치 가상패드**
- 3판 2선승, 60초 타이머
- **동적 카메라**: 거리에 따라 줌인/줌아웃, KO 시 슬로우모션+클로즈업
- 띄우기 성공 시 순간 슬로우, 히트스톱(임팩트 프레임), 화면 흔들림, 부위별 피격 모션
- 콤보 데미지 보정, 대형 콤보 카운터
- 패럴랙스 스테이지 3종 (노을 옥상 / 네온 거리 / 한강 둔치)
- 등장/승리/패배 대사 + 특정 상대 전용 라이벌 도발

- `js/data.js` 캐릭터·기술 데이터 / `fighter.js` 전투·물리 / `sprites.js` 절차 생성 픽셀아트
