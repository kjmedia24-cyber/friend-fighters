# FRIEND FIGHTERS — 친구 대전 격투 🥊

철권 스타일의 2D 픽셀아트 격투 게임. HTML5 Canvas + 순수 JavaScript로 만들어져
브라우저에서 바로 실행됩니다. 빌드 과정도, 외부 라이브러리도 없습니다.

## 실행 방법

- `index.html`을 브라우저에서 열기만 하면 됩니다.
- 또는 로컬 서버: `npx http-server .` → `http://localhost:8080`

### GitHub Pages 배포

1. 저장소 **Settings → Pages** 로 이동
2. **Source: Deploy from a branch** 선택
3. Branch를 `main`(또는 배포할 브랜치), 폴더를 `/ (root)` 로 설정 후 Save
4. 잠시 후 `https://<계정명>.github.io/friend-fighters/` 에서 플레이 가능

## 조작법

| 동작 | P1 | P2 |
|---|---|---|
| 이동 / 점프 / 앉기 | A·D / W / S | ←·→ / ↑ / ↓ |
| 약공 | F | , (쉼표) |
| 강공 | G | . (마침표) |
| 킥 | H | / (슬래시) |
| 잡기 | T | 오른쪽 Shift |
| 가드 | 상대 반대 방향키 홀드 | 동일 |

- **필살기**: ↓→ + 강공(또는 약공) — 캐릭터마다 다름
- **띄우기**: ↓→ + 킥 → 공중에 뜬 상대에게 **공중 콤보**
- **벽꽝**: 강하게 날아간 상대가 벽에 부딪히면 튕겨 나와 추가 콤보 기회
- **잡기 풀기**: 잡히는 순간 잡기 버튼
- 콤보가 길어질수록 데미지 보정이 걸립니다 (콤보 카운터 표시)
- `M`: 음소거 / `Esc`: 뒤로 가기

## 시스템

- 2인 로컬 대전 + AI 대전 (쉬움 / 보통 / 어려움)
- 3판 2선승 라운드제, 60초 타이머
- KO 슬로우모션 + 줌인, 히트스톱, 화면 흔들림, 히트스파크
- 패럴랙스 스테이지 3종: 노을 옥상 / 네온 거리 / 한강 둔치
- 캐릭터별 등장 대사, 승리 대사, 특정 상대 전용 라이벌 대사

## ★ 캐릭터를 친구들로 바꾸기 ★

**`js/data.js` 파일 하나만 수정하면 됩니다.** 각 캐릭터의 이름, 별명, 말버릇,
외형 색상(머리/피부/옷), 헤어스타일, 능력치, 필살기, 대사(등장/승리/라이벌)를
주석 설명에 따라 자유롭게 바꿔보세요. 캐릭터를 배열에 추가하면 선택 화면에도
자동으로 늘어납니다.

필살기 타입은 3종 중 선택: `uppercut`(불꽃 어퍼·띄우기) /
`rushKick`(다단 연속차기) / `quake`(가드불능 지진)

## 개발

- `js/` — `data.js`(캐릭터·설정) · `fighter.js`(전투 로직·물리) · `sprites.js`(절차 생성 픽셀아트)
  · `stages.js`(배경) · `fx.js`(연출·사운드) · `ai.js`(CPU) · `game.js`(매치 진행) · `main.js`(화면 전환·루프)
- 테스트: `node tests/smoke.js` — 헤드리스로 메뉴→대전 풀매치를 시뮬레이션
