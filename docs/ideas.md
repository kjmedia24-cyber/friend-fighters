# 아이디어 메모 (드렁큰 레슬러 2 스타일 커맨드 — 나중에 검토)

조작키: A 뒤 / S 아래 / W 위 / D 앞 (키보드 우측 하단 조작키 기준)

기본키:
- 왼쪽(뒤): 왼손 (훅)
- 아래: 오른발 (하이킥)
- 위: 왼발 (오른발을 빠르게 살짝 앞 땅을 밟는 축으로 삼고, 왼발 미들킥)
- 오른쪽(앞): 오른손 (스트레이트)

A(뒤) 조합:
- A+왼손: 백스핀블로우 / A+오른손: 어퍼컷 / A+아래: 뒤돌려차기 / A+위: 회축

W/S는 횡이동 전용 (더블클릭 X). W=왼쪽 횡이동, S=우측 횡이동.

D(앞) 조합:
- D+왼손: 오버핸드 왼손 / D+오른손: 오버핸드 오른손
- D+아래: 오른발 스트레이트 킥(앞차기, 푹 찔러넣는 킥)
- D+위: 왼발 내려찍기
